!Analisis exploratorio de ventas de vehiculos usados en Estados Unidos.

Este es un proyecto de implementacion de streamlit y plotly para la visualizacion de datos de vehiculos usados
en Estados Unidos. El proyecto permite a los usuarios explorar datos y visualizaciones interactivas relacionadas 
con el odómetro y el precio de los vehículos.

## Ejecución local

Este proyecto está desarrollado con Streamlit. Para ejecutarlo localmente, necesitas tener Python instalado.

También se puede visualizar la aplicación en línea: [Abrir aplicación en Streamlit](https://streamlit-repo-2kh1.onrender.com).

1. Abre una terminal en la carpeta del proyecto.
2. Instala las dependencias:

   ```bash
   pip install -r requirements.txt
   ```

3. Inicia la aplicación:

   ```bash
   streamlit run app.py
   ```

Streamlit mostrará en la terminal la dirección local para abrir la aplicación en el navegador.
